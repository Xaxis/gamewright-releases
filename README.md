# Gamewright Studio downloads

The built packages of [Gamewright Studio](https://gamewright.diy), a desktop app for making games
with an AI Director, for Linux, Windows and macOS. Each release here holds the packages a
version shipped and their `SHA256SUMS`. The source is private; this repository holds builds only.

Get the Studio from **[gamewright.diy/download](https://gamewright.diy/download)**: it picks the
right package for your system, shows its size and checksum, and says how to install it. What
changed in each version is on [gamewright.diy/changelog](https://gamewright.diy/changelog).

The builds are not signed yet: macOS asks you to choose Open Anyway, and Windows' SmartScreen to
choose More info, then Run anyway.
